# Operations

## Routine checks

| Frequency | Check |
|---|---|
| Per change | Review plan, role assignments and public access flags |
| Daily | Container revision health and failed requests |
| Weekly | Defender recommendations and dependency updates |
| Monthly | Cost, unused resources, access review and recovery test |
| Quarterly | Restore exercise and federation policy review |

Use Azure Monitor alerts for availability, error rate and resource saturation. Operational changes must be represented in Terraform to prevent drift.
